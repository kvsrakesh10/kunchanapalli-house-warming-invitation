# Housewarming invitation website

A static, responsive invitation page for **Friday, 20 November 2026**. It includes Telugu and English views, the three ceremony times, the venue address, Google Maps directions, an embedded map, address copy, and a link to the original Telugu invitation.

## Publish with GitHub Pages

1. Create a **private** GitHub repository named `kunchanapalli-house-warming-invitation`.
2. Upload **all files in this folder** to the repository root, keeping the `assets` folder intact.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will show the public website URL once Pages finishes publishing. For this repository name, it should be `https://kvsrakesh10.github.io/kunchanapalli-house-warming-invitation/`. Share that URL with guests.

GitHub Pages from a private repository requires a GitHub Pro, Team, or Enterprise plan. The **website itself is public** even when the repository is private, so visitors can view the delivered HTML, CSS, JavaScript, and invitation images in their browsers. [GitHub Pages eligibility](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

You can also upload the same folder to any static host, such as Netlify or Cloudflare Pages. No build command or API key is required.

The map and web fonts need an internet connection. All invitation artwork and core page features are included in the folder. The original Canva design is not modified.

## Files

- `index.html` — page content and links
- `styles.css` — layout and visual design
- `script.js` — language switch, address copy, and sharing
- `assets/` — image crops and the original invitation PNG
